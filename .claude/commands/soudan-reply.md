# /soudan-reply

`$ARGUMENTS` は問い合わせ本文（貼り付けたもの）。このコマンドは下書きを作るだけ。送信は依頼主がご自身のメールソフト・LINE から行う。

## 手順1. 整理

1. 相談内容を1行にまとめる：誰が（親・きょうだい等の立場）、何を知りたい・したいか、期限があるか。
2. 対応するページを選ぶ：`service-koken.html`（任意後見・見守り）、`service-shintaku.html`（民事信託）、`service-yuigon.html`（遺言）、`service-kyoninka.html`（各種許認可・諸手続）、`service-renkei.html`（専門職へのおつなぎ）、`money.html`・`kurashi.html`・`sumai.html`、関連する `news/` 記事。
3. 次のいずれかに当たれば、返信は受け止めと確認事項・面談の案内にとどめ、見通しや結論は書かない。どれに当たったかを依頼主に日本語で伝える：
   - 親族間の争い・紛争（弁護士）
   - 法定後見の申立て（司法書士・弁護士）
   - 相続税・贈与税など税務の判断（税理士）
   - 障害年金（社会保険労務士）
   - 期限が迫っている、ご本人の判断能力が急に低下している

## 手順2. 事実

制度・手続・金額を書くときは、既存ページ・記事に書いてある範囲か、`law-verifier` で確認したものに限る。確認できないことは「面談で状況をうかがって確認します」と書く。

## 手順3. 下書き

- 最初の文で、問いへの答えか次の一歩を書く。
- やさしい言葉で。専門用語には短い説明を添える。
- 報酬額は書かない（サイトに掲載していないため。必要なら依頼主に確認）。
- 保証・断定（「必ず」「大丈夫です」）をしない。
- 業務範囲外は「信頼できる専門職におつなぎします」と書く。
- 次の一歩：無料相談の案内（`https://oyanakigo.com/#contact`）と関連ページのURL。
- 署名は `[署名]` のままにする。

下書きは `drafts/soudan-<YYYY-MM-DD>-<短い識別名>.md` に保存する（`drafts/` は .gitignore 済み。個人情報を含むのでコミットしない）。

## 手順4. レビュー

`logic-checker` に下書きのパスを渡す。blocking を直して1回だけ再実行する。major も原則反映する。

## 依頼主への出力（日本語）

1. 相談内容の1行要約と、関連ページ。
2. 当てはまった注意点（手順1-3）と、残った指摘。
3. コピーしやすいよう、下書き全文を1つのコードブロックで。
4. 一言：「送信前に内容をご確認のうえ、ご自身のメール・LINE から送ってください。」

## しないこと

- 送信する、送ったと書く。
- 相談者の個人情報を検索語・コミットするファイル・公開ページに入れる。
- `drafts/` をコミットする。
